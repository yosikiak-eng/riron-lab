楽器の音

作曲でよく使う楽器の音を、鍵盤とフレーズで聴き比べられます。シンセで特徴をまねた音なので、本物の録音とは少し違います。楽器の役割や組み合わせを考えるのに使ってください。

ジャンル別の特徴

ジャンルを選ぶと、リズム・コード・よく使う楽器と、その雰囲気のデモが聴けます。

楽器の分類

楽器は、何がふるえて音が出るかで仲間分けできます。

弦楽器
弦のふるえで鳴る。こする（バイオリン・チェロ）、はじく（ギター・ベース・琴・三味線・チェンバロ）、たたく（ピアノ）に分かれます。
木管楽器
息で空気をふるわせる。フルート・尺八（歌口に息を当てる）、クラリネット・サックス（リードといううすい板をふるわせる）。サックスは金属製でも木管の仲間です。
金管楽器
くちびるのふるえで鳴る。トランペット・トロンボーン・ホルン・チューバ。
打楽器
たたいて鳴らす。皮を張った膜鳴楽器（ドラム・和太鼓）と、本体そのものが鳴る体鳴楽器（シンバル・マリンバ・グロッケン・ビブラフォン）。
鍵盤楽器
鍵盤で操作する楽器のまとめ方。ピアノは「打弦楽器」、オルガンは「管楽器」の仲間でもあります。
電子楽器
電気で音を作る楽器。シンセサイザー・リズムマシン・エレピ・電子オルガンなど。
声
ボーカル、合唱、そして歌声合成ソフト。いちばん表情豊かな「楽器」です。

音色を決める3つの要素

倍音
1つの音の中に含まれる、高い成分の量と並び方。倍音が多いと明るく鋭い音（のこぎり波・トランペット）、少ないと丸く柔らかい音（サイン波・フルート）になります。
エンベロープ
音の立ち上がりから消えるまでの形。シンセでは A（アタック：鳴りはじめの速さ）、D（ディケイ：落ち着くまで）、S（サステイン：伸ばしている間の大きさ）、R（リリース：離してから消えるまで）の4つで表します。ピアノは A が速く S がない、パッドは A も R も長い、という違いです。
音域
同じ楽器でも、低い音は太く暗く、高い音は細く明るく聴こえます。楽器ごとの「おいしい音域」を使うのがコツです。
聴き比べのヒント：「体験」タブで、ピアノ（すぐ消える）とシンセパッド（ゆっくり立ち上がる）を同じ鍵盤で弾くと、エンベロープの違いがよくわかります。

組み合わせて聴く

C → Am → F → G の4小節を、いろいろな編成で鳴らします。

編成づくりのコツ：低音はベース、中音は和音（ピアノ・ギター・パッド）、高音はメロディ、と音域で役割を分けると、たくさん重ねても濁りません。同じ音域に楽器を重ねすぎない、歌がある間は伴奏を引き算する、の2つも覚えておくと便利です。

01

音の名前と鍵盤

音楽理論の話は、ほとんどが「鍵盤のどこにあるか」と「何個はなれているか」で説明できます。まずは鍵盤を弾いて、音の並びに慣れましょう。

鍵盤を弾いてみる

鍵盤をタップしてね
隣り合う鍵盤（黒鍵も含む）の距離が 半音。半音2つぶんが 全音。E–F と B–C の間には黒鍵がないので、ここだけ白鍵どうしで半音。

音名の対応表

英米（コード名）CDEFGAB
イタリア（階名）ドレミファソラシ
日本ハニホヘトイロ

「ハ長調」＝Cメジャー、「イ短調」＝Aマイナー。DAW やコード表記では英語を使うので、C〜B に慣れておくと便利です。

たとえで覚える

鍵盤は階段
となりの鍵盤へ1つ進むのが「半音」で1段、2つ進むのが「全音」で2段です。白鍵か黒鍵かは関係なく、とにかく1段ずつ数えます。
音名は住所
ド・レ・ミは日本の呼び方、C・D・E は世界共通の呼び方です。同じ場所に、2通りの住所の書き方があるようなものです。
オクターブは同じ名前の上の階
ドから数えて8つ目のドは、同じ名前の1つ上の階にいる「同じ音」です。高さは違っても、仲間に聴こえます。
♯と♭は1段上がる・下がる
♯は1段上がる、♭は1段下がる合図です。C♯ と D♭ のように、同じ段を別の名前で呼ぶこともあります。

♯（シャープ）と ♭（フラット）

♯ は半音上げる、♭ は半音下げる記号。C♯ と D♭ は鍵盤上では同じ黒鍵（異名同音）。どちらで書くかはキー（調）で決まります。

「C4」の数字はオクターブ番号。ピアノ中央のドが C4、その上の C が C5。DAW によっては C3 と表示されることもあるので注意。

02

リズムとビート

音符の長さとテンポを確かめたら、ドラムを打ち込んでみましょう。1マスが16分音符、16マスで1小節です。

音符の長さ（4/4拍子・1小節）

4/4拍子は「1小節に4分音符が4つ」。音符を細かくするほど、1小節に入る数が倍になります。

ステップシーケンサー

1マス＝16分音符。4マスで1拍、16マスで1小節。マスをタップして打ち込もう。

4つ打ち：キックを毎拍（1・5・9・13マス目）。ダンス系の基本。
8ビート：ハイハットを8分（1つおき）、スネアを2・4拍目（5・13マス目）、キックは1拍目から。ロック・ポップスの基本。
速い曲は BPM 160〜200 くらいがよく使われます。

たとえで覚える

拍は心臓の鼓動
曲の中でずっと一定に刻まれている「トン、トン」が拍です。止まらない心臓の鼓動のように、すべてのリズムの土台になります。
小節は箱
4/4拍子なら、4つの拍が入る箱がずっと並んでいます。音符はその箱の中にどう詰めるかを表します。
音符の長さはピザの切り分け
全音符が丸ごと1枚、2分音符が半分、4分音符が4分の1枚、8分音符が8分の1枚です。
BPM は歩く速さ
BPM60 はゆっくり散歩、BPM120 は早歩き、BPM170 は駆け足くらいの感覚です。
4つ打ちは行進の足音
「ドン・ドン・ドン・ドン」と毎拍キックが鳴るのは、みんなで足をそろえて歩く行進のリズムです。体が自然に揺れます。
裏拍は手拍子の「チャ」
「ン・チャ・ン・チャ」の「チャ」の位置が裏拍です。ここを強調すると、軽快に跳ねるノリになります。
03

音程（インターバル）

2つの音の距離を「度」で表します。半音いくつぶんか、どんな響きか、をセットで覚えます。

音程一覧

行をタップすると、C からの音程が鳴ります。

覚え方：「長・短」は2・3・6・7度に、「完全」は1・4・5・8度に付く。長3度（明るい）と短3度（暗い）の違いが、メジャーとマイナーの違いそのもの。

たとえで覚える

音程は定規
2つの音の距離を、半音という目盛りで測るのが音程です。
長3度は晴れ、短3度は曇り
たった半音の違いで、明るい空と曇った空ほど印象が変わります。コードの明暗を決めるのはこの3度です。
完全5度は建物の柱
がっしりして揺るがない響きです。だからロックのパワーコードや、ベースの土台によく使われます。
増4度は綱渡り
どこにも落ち着けない、不安定な響きです。この不安定さが、ドミナントの「帰りたい」気持ちの正体です。
04

スケール（音階）

曲で使う音のセットがスケールです。全音と半音の並び方が同じなら、どの音から始めても同じ種類になります。

メジャーとマイナーは親戚

C メジャーと A マイナーは、使う音がまったく同じ（白鍵だけ）。始まる音が違うだけ。この関係を 平行調 と呼びます。

チャーチモード：ドリアン・フリジアン・リディアン・ミクソリディアンは、メジャースケールを別の音から始めたもの。1音だけ違う「色」を感じてみよう。

たとえで覚える

スケールは絵の具セット
12色の中から7色を選んだセットです。その曲では、基本的にこのセットの色だけで絵を描きます。
主音は家
スケールのいちばん最初の音が「家」です。メロディは家から出かけて、最後に家へ帰ってくると落ち着きます。
メジャーとマイナーは昼と夜
同じ景色でも、昼の光で見るか、夜の光で見るかで印象が変わります。
ペンタトニックはにごらない5色
ぶつかりやすい2音を抜いた5音です。どう並べても失敗しにくいので、アドリブの入門にぴったりです。
05

コード（和音）

ルートから3度ずつ音を重ねたものがコードです。3度が長いか短いかで、明るさが決まります。

コードネームの読み方

表記意味
C大文字だけ → メジャー（R・長3度・完全5度）
Cmm → マイナー（3度が短3度）
C77だけ → 短7度を追加（セブンス）
CM7 / Cmaj7M7 → 長7度を追加（メジャーセブンス）
Cm7-5マイナーセブンスの5度を半音下げる
C/E分数コード：C のコードで、一番下（ベース）を E にする

たとえで覚える

コードはおだんご
ルートの上に、1つ飛ばしで音を串に刺していくのがコードです。3つ刺せば3和音、4つ刺せば4和音（セブンス）です。
ルートは名前の由来
いちばん下の土台の音がルートで、コードの名前もこの音から付きます。
3度は表情
真ん中の3度が長いか短いかで、笑顔（メジャー）にも、泣き顔（マイナー）にもなります。
7th は料理のスパイス
3和音にもう1音足すと、ぐっと大人っぽい味になります。足しすぎると何の料理かわからなくなるのも同じです。
06

ダイアトニックコード

スケールの音だけで作れる7つのコードです。ローマ数字で覚えておくと、キーが変わっても同じ考え方で使えます。

T トニック（安定・ホーム）SD サブドミナント（展開）D ドミナント（緊張→解決したい）

機能（ファンクション）の流れ

T → SD → D → T が基本の流れ。「安定 → 展開 → 緊張 → 解決」というストーリー。

代理コード：同じ機能のコードは入れ替えOK。Ⅰ の代わりに Ⅵm、Ⅳ の代わりに Ⅱm を使うと、雰囲気だけ変えて流れはそのまま。

たとえで覚える

ダイアトニックは同じ名字の家族
キーという名字を持つ7人家族です。同じスケールの音だけでできているので、誰を並べても仲よく聴こえます。
T・SD・D は家・お出かけ・帰り道
トニックは家、サブドミナントはお出かけ先、ドミナントは帰り道です。家を出て、帰り道を通って、家に帰ると「おしまい」になります。
Ⅴ7 → Ⅰ は「ただいま」
帰り道の最後の角（Ⅴ7）を曲がって玄関を開ける瞬間です。いちばん「帰ってきた」と感じる動きです。
07

定番コード進行

J-POPやボカロ曲でよく使われる進行を、好きなキーとテンポで聴けます。

青がベース音、黄色が上のコード音です。コードをタップすると単体で鳴ります。上の音がなるべく動かないように並べる（ボイスリーディング）と、なめらかに聴こえる。

たとえで覚える

コード進行は物語の並べ方
同じ登場人物（コード）でも、並べる順番で物語が変わります。起承転結の並べ方の型が、名前の付いた進行です。
王道進行は定番料理
誰が作っても安心しておいしい、J-POP の定番の味です。少しアレンジするだけで個性も出せます。
カノン進行は階段を下りる
ベースが1段ずつ下がっていくので、穏やかで感動的に聴こえます。
小室進行は助走路
暗い Ⅵm から始まって、一気に駆け上がるドラマチックな進行です。
ツーファイブは最短の帰り道
Ⅱm7 → Ⅴ7 → Ⅰ は、家（Ⅰ）へまっすぐ帰る黄金ルートです。ジャズではこの道を何度も通ります。
ループ進行は回転ドア
最後のコードから最初のコードへ自然に戻れるので、何周してもつながります。
08

メロディを作ってみよう

黄色のマスが、その小節のコードの構成音です。小節の頭にコードトーンを置き、間を自由につなげてみましょう。

メロディ作りの基本

用語意味
コードトーンそのとき鳴っているコードの構成音。拍の頭に置くと安定して聴こえる。
経過音コードトーンとコードトーンの間を順番につなぐ音。なめらかさが出る。
刺繍音コードトーンから隣の音へ行って、すぐ戻る音。動きが出る。
跳躍3度以上大きく飛ぶこと。サビの印象的な部分に使うと効果的。飛んだあとは逆方向に順次進行で戻ると自然。
ヒント：同じリズムやフレーズを「くり返して」「少し変える」と覚えやすいメロディになります。

たとえで覚える

メロディは会話
前半で問いかけて、後半で答える。会話のように受け答えがあると、自然で覚えやすいメロディになります。
コードトーンは踏み石
強拍に置くコードトーンは、川を渡るときの大きな踏み石です。そこに乗っていれば安定します。
経過音は小石
踏み石と踏み石のあいだに置く小石です。なめらかに渡るための足場になります。
モチーフはキャラクター
何度も登場するキャラクターほど覚えてもらえるように、同じモチーフをくり返すとメロディが記憶に残ります。

いいメロディの3つの条件

覚えやすい
同じリズムや形がくり返されている。一度聴いたら口ずさめる。
自然に歌える
音域が広すぎず、息継ぎの場所がある。跳躍のあとに無理がない。
ドラマがある
低いところから高いところへの山と谷がある。緊張と解決、問いかけと答えがある。

この3つは、どれか1つだけ強くてもだめです。くり返しばかりだと退屈、ドラマばかりだと覚えられません。

作り方の手順

  1. コード進行とテンポを決める先に土台があると、メロディの音を選びやすくなります。迷ったら王道進行や小室進行から。
  2. リズムだけで短いモチーフを作る1〜2小節ぶんの「タタ・ターン・タ」のようなリズムを、手拍子や鼻歌で先に決めます。印象に残るのは音の高さより、まずリズムです。
  3. 強拍にコードトーンを置いて音をつける小節の頭や拍の頭はコードの音にして、あいだを経過音や刺繍音でつなぎます。
  4. くり返して、少し変える同じモチーフをもう一度使い、最後だけ変えたり、高さをずらしたりします（下の「モチーフを育てる技」）。
  5. 山（いちばん高い音）の場所を決める頂点はサビの中で1回だけ。そこへ向かって少しずつ上がっていく道筋を作ります。
  6. 終わり方を決める区切りの最後を主音にすると「終わった」、主音以外にすると「続く」感じになります。
  7. 声に出して歌ってみる息が続くか、高すぎないか、口ずさめるかを確かめます。歌えないところは直す候補です。

モチーフを育てる技

いいメロディの多くは、短いモチーフをいろいろな形で使い回しています。新しい素材を足し続けるより、1つの素材を育てるほうが、まとまりのある覚えやすいメロディになります。

  • 反復：そのままくり返す。いちばん強く記憶に残る。
  • ゼクエンツ（反復進行）：形はそのままで、高さだけずらしてくり返す。自然に展開していく。
  • リズムはそのまま、音だけ変える：同じフレーズの続きに聴こえるのに、景色が変わる。
  • A・A・A'・B：3回目で少し変え、4回目で別の展開へ。J-POP のサビでよく使われる型。
  • 反行：モチーフの上下を逆にする。上がっていた形を下がる形にすると、答えのように聴こえる。

メロディの形（輪郭）

音の高さの流れを線でなぞったときの形を、メロディの輪郭といいます。輪郭がはっきりしていると、聴き手は流れを追いやすくなります。

  • アーチ型：上がって、山を越えて、下りてくる。いちばん安定した形。
  • 頂点は1回だけ：いちばん高い音を何度も使うと特別感が薄れる。
  • 跳躍のあとは反対向きへ：大きく上がったら、隣の音へ下りて着地する。跳びっぱなしは不安定に聴こえる。

リズムで差をつける

  • 食い（シンコペーション）：次の拍の音を、半拍前に出す。前のめりな勢いが出る。J-POP やボカロのサビの定番。
  • 休符から入る：小節の頭を休んで、裏拍から歌い出す。軽やかで、言葉が立つ。
  • 細かい音と長い音の対比：細かく動いたあとに長い音を置くと、その長い音が強く印象に残る。
  • アウフタクト（弱起）：前の小節の終わりから歌い始める。「さあ行くぞ」という助走になる。

Aメロ・Bメロ・サビの作り分け

AメロBメロサビ
音域低め・狭め少しずつ上がるいちばん高い。頂点がある
音の細かさ細かく、語るようにだんだん長く長い音で歌い上げる
くり返し多め変化をつける覚えやすい決めフレーズ
終わり方続く感じⅤ で止めて期待させる主音でしっかり着地
サビ頭の「決め音」：サビの最初の音は、Aメロ・Bメロで使っていない高さから入ると「ここからサビ」とはっきり伝わります。

終わり方で印象が変わる

フレーズの最後の音で、聴き手の感じ方が大きく変わります。

前半は「続く」、後半は「完結」で終えると、問いかけと答えのペアになります。

歌声合成（ボカロ）でメロディを作るとき

  • 人には歌えない速さ・高さも武器になる：早口や超高音は歌声合成ならではの魅力。ただし、曲の中の見せ場に絞ると効果が上がります。
  • 速いフレーズは言葉を選ぶ：子音が多い言葉を細かい音符に詰めると聴き取りにくくなります。母音で伸ばせる言葉を山場に置きます。
  • 息継ぎの休符を入れる：機械は息が切れませんが、休符がないと聴く側が苦しくなります。人らしさのためにも区切りを作ります。
  • ハモリは3度下か6度下：主旋律の3度下を基本に、ぶつかるところだけ別の音に逃がします。

行き詰まったときの抜け出し方

  • 鼻歌を録音する：コードを1つ鳴らしながら、なんとなく歌ったものをスマホで録っておく。あとで聴き返すと使える断片が見つかります。
  • リズムだけ借りる：好きな曲のメロディのリズムだけを借りて、音の高さを全部変える。リズムは著作権の心配が少なく、骨組みとして強力です。
  • 制限をつける：「3つの音だけ」「1オクターブ以内」など縛りを作ると、かえってアイデアが出ます。
  • サビの決め音から逆算する：いちばん言いたい言葉といちばん高い音を先に決め、そこへ向かう道を作ります。
  • 一晩置く：作った直後は良し悪しがわかりません。翌日に聴いて、残ったものが本物です。

できたメロディのチェックリスト

  • 声に出して歌える？ 息が続く？
  • いちばん高い音はサビに1回だけ？
  • 全体の音域は1オクターブ半くらいに収まっている？
  • 同じモチーフが、くり返し・変化して使われている？
  • 強拍にコードにない音を長く置いたままになっていない？
  • 大きく跳んだあと、反対向きに戻っている？
  • フレーズの最後が、続くところと終わるところで使い分けられている？
  • 次の日に聴いても、口ずさみたくなる？

タップするとチェックできます。体験タブのメロディ作りで試しながら使ってみてください。

転調と応用コード

ラスサビでキーを上げる転調と、ダイアトニックの外から借りてくるコードを聴き比べます。

ラスサビ転調

Ⅳ→Ⅴ→Ⅲm→Ⅵm を1周したあと、キーを上げてもう1周します。

Ⅴ7 経由：新しいキーのⅤ7（ドミナント）を1つ挟むと、いきなり変わるより自然に転調できる。

同主調と平行調

同主調：ルートが同じでメジャー↔マイナー（C ↔ Cm）。平行調：使う音が同じ（C ↔ Am）。

たとえで覚える

転調は舞台の移動
同じ物語を、別の舞台に移して続けることです。ラスサビの半音上げは、照明をひとつ明るくするような変化です。
ピボットコードは乗り換え駅
元のキーにも新しいキーにもあるコードは、2つの路線が交わる乗り換え駅です。ここを経由すると、気づかないうちに乗り換えられます。
近親調は親戚の家
共通する音（家具）が多いキーどうしは、親戚の家のように気軽に行き来できます。

リハモ（実戦コード理論）

メロディはそのままで、下のコードを付け替えるのがリハーモナイズ（リハモ）です。候補を選んで聴き比べながら、実際の曲づくりで使える差し替えのパターンを身につけましょう。

リハーモナイズとは

メロディはそのままで、下で鳴るコードを別のものに付け替えることです。同じメロディでも、コードが変わるだけで明るさや切なさ、おしゃれさが大きく変わります。2番やラスサビで変化をつけたり、ありがちな進行から抜け出したりするのに使います。

付け替えの手順

  1. メロディの大事な音を見つける：拍の頭の音と、長く伸ばす音。
  2. その音を含むコードを候補にする：その音がコードトーンかテンションになるコード。
  3. 機能を確かめる：元のコードと同じ機能（T・SD・D）なら、流れを保ったまま置き換えられる。
  4. 向かう力を足す：次のコードの前に、セカンダリードミナント・ツーファイブ・裏コードを置く。
  5. 色を変える：4和音・テンション・借用和音・サブドミナントマイナーで雰囲気を整える。
  6. ベースラインを確かめる：ベースが跳びすぎず、なめらかに動いているか。

たとえで覚える

リハモは衣装替え
同じ歌（メロディ）に、別の衣装（コード）を着せることです。歌は同じでも、雰囲気ががらりと変わります。
代理コードは代役の俳優
同じ役（機能）を演じられる別の俳優です。顔ぶれが変わっても、物語は成り立ちます。
セカンダリードミナントは紹介の前フリ
次に出てくるコードを「それでは登場していただきましょう！」と紹介するような役目です。
裏コードは裏道
同じ目的地へ向かう、もう1本の道です。景色は違っても、ちゃんと同じ家にたどり着きます。

トニック・サブドミナント・ドミナント

コードには、曲の中での役割（機能）があります。リハモは「同じ役割のコードに差し替える」か「役割の流れそのものを変える」かのどちらかです。

Tトニック
家。安定していて、ここで終われる。キー C なら C・Em・Am（Ⅰ・Ⅲm・Ⅵm）。
SDサブドミナント
外出。家から離れて景色が広がる。F・Dm（Ⅳ・Ⅱm）。
Dドミナント
帰り道。緊張していて、家（トニック）に帰りたがる。G7・Bm7-5（Ⅴ7・Ⅶm7-5）。

流れの基本形

T → SD → D → T がいちばん基本の流れです。安定 → 広がり → 緊張 → 解決、という物語になります。ポップスやロックでは D → SD と戻る流れもよく使います。

ドミナントが帰りたがる理由

G7 の中には B と F が入っています。この2音は増4度（トライトーン）という、いちばん不安定な音程です。B は半音上の C へ、F は半音下の E へ動くと安定し、ちょうど C コードの音になります。だから G7 のあとに C が来ると「解決した」と感じます。

ルートの「強進行」

ルートが完全5度下（＝完全4度上）へ動くと、いちばん自然で力強く聴こえます。G→C、D→G、A→D…。セカンダリードミナントやツーファイブがよく効くのは、この動きを連鎖させているからです。

キー CⅠⅡmⅢmⅣⅤⅥmⅦm-5
コードCDmEmFGAmBm7-5
機能TSDTSDDTD
ラボの見方：コードの下の色のついた記号が機能です。D→はセカンダリードミナント（次のコードへ引っぱる）、SDmは借用和音やサブドミナントマイナー（切なさ・ドラマ）、経過は経過和音です。上のグラフは、緊張の高さをつないだものです。

BPM とリハモの関係

BPM は1分間に4分音符がいくつ入るか。BPM120 なら1拍は 0.5 秒、4/4拍子の1小節は 2 秒です（1小節の秒数 ＝ 240 ÷ BPM）。

コードが変わる間隔をハーモニックリズムといいます。同じ進行でも、BPM によって聴こえ方が大きく変わります。

リハモの密度はテンポで決める

  • 遅い曲（〜90）：1小節を2つに分けて、ツーファイブやセカンダリードミナントを挟む余裕がある。細かい差し替えがよく聴こえる。
  • 速い曲（140〜）：コードを細かく変えすぎると、せわしなく聴こえる。差し替えはサビ前など要所だけにして、基本は1小節に1つか、2小節に1つ。
  • ボカロの速い曲：BPM が速くても、ハーフタイム（半分の速さに感じるリズム）のサビでは、遅い曲と同じ密度でリハモできる。
ラボで試す：上の BPM スライダーで速さを変えて、「ジャズ風」のおまかせを 70 と 160 で聴き比べてみてください。

ジャンル別の定番リハモ

J-POP・ボカロ
王道進行の Ⅲm を Ⅲ7 に。次の Ⅵm へ強く引っぱり、切なさが増す。ラスサビの半音上げ転調も定番。
シティポップ
M7・9th で全体をおしゃれに。丸サ進行のようにセカンダリードミナントでつなぐ。
ジャズ

ドミナントを避けて ♭Ⅶ で解放感。3度を抜いたパワーコードなら、機能はさらにあいまいになる。
バラード
Ⅳ→Ⅳm→Ⅰ のサブドミナントマイナーで泣かせる。ベースを半音ずつ下げるクリシェも定番。
