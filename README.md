# 音楽理論ラボ（PWA版）

スマホのホーム画面に追加して、アプリのように使える版です。一度開けば、オフラインでも動きます。

## ファイル構成

```
index.html             アプリ本体
manifest.webmanifest   アプリ名・アイコン・色の設定
sw.js                  オフライン用のサービスワーカー
icons/                 アイコン（192px, 512px, マスカブル, Apple用, ファビコン）
```

## GitHub Pages で公開する手順（無料）

1. GitHub で新しいリポジトリを作る（例：`riron-lab`、Public）
2. このフォルダの中身をすべてアップロードする
   - ブラウザなら「Add file → Upload files」にファイルとフォルダをドラッグ
3. リポジトリの「Settings → Pages」を開く
4. 「Source」を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
5. 1〜2分後、`https://ユーザー名.github.io/riron-lab/` で開けるようになる

PWA は https で配信されている必要があります。GitHub Pages は最初から https なので、そのまま使えます。

## ホーム画面への追加

- **iPhone（Safari）**：共有ボタン →「ホーム画面に追加」
- **Android（Chrome）**：ページ下の「ホーム画面に追加」ボタン、またはメニュー →「アプリをインストール」

## 手元で動作確認する

`index.html` を直接ダブルクリックで開くと、サービスワーカーは動きません。簡易サーバーを立ててください。

```
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

## 中身を更新したとき

`index.html` などを書き換えたら、`sw.js` の先頭にある `VERSION` を `'v2'` のように上げてからアップロードしてください。上げないと、インストール済みの端末で古い版が表示され続けることがあります。

## 補足

- 進み具合（ポイント・課題・スタンプ）は端末のブラウザに保存されます。別の端末とは共有されません。
- iPhone では、ホーム画面から開いたアプリとブラウザの Safari とで、保存データが別々になります。
- iPhone は、マナーモード（消音スイッチ）がオンだと音が出ないことがあります。
